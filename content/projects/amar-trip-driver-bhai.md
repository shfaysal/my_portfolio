## Highlights
- Accept/decline trip requests with live ETAs and status updates.
- Guided flow for arrive → start trip → end trip with turn-by-turn navigation.
- Driver earnings, trip history, and wallet payouts in one place.
- Safety features including SOS, share trip, and masked calling/chat.
- Backend support for smart matching, surge/bonus rules, and reliable notifications.

## Tech Notes
- Kotlin and Jetpack Compose for a modern, smooth Android UI.
- REST APIs for core backend flows (auth, trips, earnings, profile).
- WebSockets and Pusher for real-time trip updates and instant ride requests.
- Push notifications for alerts when the app is closed.
- Google Maps for live location tracking, routing, and ETAs.
